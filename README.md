# Портфолио Яны Пономаревой

Адаптивный одностраничный сайт-портфолио, подготовленный для публикации через GitHub Pages.

## Публикация

1. Загрузите все файлы из этой папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`.
5. Нажмите **Save**.

Главный файл сайта — `index.html`.
