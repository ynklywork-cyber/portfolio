# Yana Portfolio Pro

Профессиональная версия сайта-портфолио.

## Загрузка в GitHub

Замените текущие файлы репозитория файлами из этого архива, сохранив папку `assets`.

Структура:
- index.html
- style.css
- script.js
- assets/

GitHub Pages должен публиковаться из ветки `main`, папка `/ (root)`.
